### 📌 阶段一：打破黑盒，从零搭建本地大模型
- **痛点**：缺乏GPU服务器，不知如何本地化部署大模型。
- **行动与突破**：
  - 放弃600GB原生权重模型，学会使用 **Ollama**。
  - 理解 **GGUF量化格式**，成功拉取并运行 `qwen2.5:7b` 和 `14b`。
  - 掌握命令行交互与API调用。
- **能力提升**：理解了本地大模型的显存占用原理、量化机制，掌握模型托管工具。

---

### 📌 阶段二：容器化与可视化编排
- **痛点**：命令行对话不够直观，需要专业的微服务架构管理AI。
- **行动与突破**：
  - 克服 WSL 2 安装难题，配置国内镜像加速器，部署 **Docker Desktop**。
  - 搭建 **Dify** 平台，解决“容器无法访问宿主机”的经典网络问题。
- **能力提升**：掌握Docker基础操作、微服务概念，以及API密钥管理思维（使用环境变量 `.env`）。

---

### 📌 阶段三：全栈开发与桌面端打包
- **痛点**：需要落地一个真正属于自己的交互软件。
- **行动与突破**：
  - 使用 **Python FastAPI** 开发后端接口，**HTML/CSS/JS** 开发前端界面。
  - 理解**跨域（CORS）**，使用 `fetch` 异步请求。
  - 使用 **Electron** 将网页打包为独立的 Windows 桌面应用（`.exe`）。
- **能力提升**：打通“前端UI -> 后端逻辑 -> 模型推理”全链路，掌握前后端分离开发范式。

---

### 📌 阶段四：多模态融合与计算机视觉
- **痛点**：纯文本模型无法解决“看图诊断农作物/牲畜”的农业刚需。
- **行动与突破**：
  - 训练并跑通 **YOLO (YOLOv11)** 目标检测，实现实时推理。
  - 引入 **Minicpm-v / Llava** 多模态视觉模型。
  - 打通“YOLO提取标签 -> 前端缓存Base64 -> 多模态大模型读图诊断”闭环，实现**上下文多轮对话记忆**。
- **能力提升**：掌握计算机视觉基础、多模态模型输入输出机制及对话状态管理。

---

### 📌 阶段五：Harness架构与复杂逻辑调度
- **痛点**：大模型在RPG游戏中容易产生幻觉，不按规范输出。
- **行动与突破**：
  - 深入 **DeepSeek Harness (DSH)** 源码，理解 Agent Loop。
  - 为“华小洁”注入专属人设Prompt。
  - 设计**“双轨制游戏逻辑”**：前端JS负责概率和数值判定，大模型只负责剧情叙事，解决AI乱改数值Bug。
  - 引入 `mode` 参数，实现同一套后端API处理聊天与游戏两种业务。
- **能力提升**：掌握系统提示词工程、Agent编排思维，以及“状态机隔离”的架构设计。

---

## 总结

> “这几天，我完成了一个名为‘华小洁’的农业多模态智能体。这不仅仅是一个聊天机器人，而是一个全栈工程。
