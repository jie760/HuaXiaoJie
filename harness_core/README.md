# 华小洁 · Harness 智能体调度中枢

## 📖 模块简介
本模块基于 DeepSeek Harness (DSH) 源码进行定制。它是“华小洁”项目的“大脑调度层”。相比于普通的对话机器人，Harness 负责统筹规划、工具调用与多步推理，赋予了华小洁主动解决复杂农场问题的能力。

## 🛠️ 核心定制点
1. **系统提示词注入**：在 `.agents/` 目录下自定义了 `huaxiaojie.json`，注入了“华南农业大学专属兽医”的人设。
2. **多模态工具挂载**：预设了调用本地 YOLO API 和 Minicpm-v 多模态模型的快捷指令。
3. **规则引擎**：定义了“方案A/B/C”的诊疗与判定逻辑，支持农场RPG游戏玩法。

## 🚀 启动方式
```bash
# 1. 安装依赖
pnpm install

# 2. 编译构建
pnpm run build

# 3. 启动 Web UI 控制台
pnpm dsh web

# 4.启动后访问 http://127.0.0.1:3080 即可进入调度台
